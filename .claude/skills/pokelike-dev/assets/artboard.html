POKELIKE ARTBOARD

Palettes

Each palette is a 4-step ramp (g0 light → g3 outline) plus feature colours. A ramp that only changes lightness reads flat; hue-shifting the dark end toward blue and the light end toward yellow is what makes it look painted rather than dimmed.

Generated maps — one per theme

Same node graph in every theme, so differences you see are the painter's, not the layout's.

Canvas sprites

These are the node markers on the map. They are drawn at 16–20px and must read at that size — squint at the 1× column, not the magnified one.
